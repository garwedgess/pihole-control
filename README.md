# PiHole Control - Android App

[![CircleCI](https://circleci.com/bb/wedgess/pihole-control/tree/develop.svg?style=shield)](https://app.circleci.com/pipelines/bitbucket/wedgess/pihole-control?branch=develop)
[![codecov](https://codecov.io/bb/wedgess/pihole-control/branch/develop/graph/badge.svg?token=O47T8Z99GM)](https://codecov.io/bb/wedgess/pihole-control)

**PiHole Control** is an Android application designed to provide a convenient way to manage and control your [Pi-hole](https://pi-hole.net/) ad-blocking server.

## Description

This app allows you to:

*   Enable and disable ad-blocking.
*   View statistics about your Pi-hole's activity.
*   Manage your Pi-hole's blocklists and whitelists.
* And much more!

## Pi-hole

[Pi-hole](https://pi-hole.net/) is a network-level ad and internet tracker blocking application which acts as a DNS sinkhole.

## Features

*   **Easy to use:** Simple and intuitive interface.
*   **Remote control:** Control your Pi-hole from anywhere.
*   **Statistics:** View detailed statistics about your Pi-hole's activity.
*   **Blocklists and Whitelists:** Manage your blocklists and whitelists.

## Getting Started

To get started with PiHole Control, you'll need to:

1.  Have a working Pi-hole server set up on your network.
2.  Install the PiHole Control app on your Android device.
3.  Configure the app with your Pi-hole's IP address and API token.
